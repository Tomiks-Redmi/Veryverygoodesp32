# VeryGood ESP32

Многофункциональная прошивка для ESP32. Собирает в одно устройство OLED-дисплей, энкодер, датчики температуры, сонар, датчик движения, джойстик, бузер и реле. Управлять можно энкодером, джойстиком или с телефона через веб-панель по WiFi.

Меню на экране на русском, у каждого пункта своя иконка. Всё работает без блокировок: экран обновляется примерно 30 раз в секунду, датчики опрашиваются в фоне.

## Возможности

| Раздел | Что делает |
|---|---|
| **Панель** | Обзор всех датчиков плитками. Отдельные крупные страницы для DS18B20, DHT11, влажности (с точкой росы), расстояния и движения. По OK включается автолистание страниц. |
| **Графики** | История температуры, влажности, расстояния и аналогового входа. Масштаб подбирается сам, видны мин/макс. Шаг записи от 1 с до 5 мин. |
| **Часы** | Время по интернету (NTP) или с телефона: достаточно открыть веб-панель. Крупные часы с датой и температурой, **будильник** с выбором мелодии и дней (будни, выходные, каждый день) и отсрочкой на 5 минут. |
| **Сонар** | Анимированный радар и **парктроник**: пищит тем чаще, чем ближе препятствие. Скорость звука поправляется на текущую температуру. |
| **Охрана** | Постановка с задержкой на выход. Тревогу поднимают PIR и/или сонар. Сирена, мигание экрана, реле и журнал событий. Снятие может быть защищено PIN-кодом. |
| **Реле** | Режимы: вручную, **термостат** (нагрев или охлаждение, с гистерезисом), включение по тревоге, **свет по движению** на N секунд. |
| **Джойстик** | Показывает положение ручки, сырые значения АЦП и калибрует центр. |
| **Игры** | Змейка, «Ловец звёзд», понг против компьютера, тест реакции, **терменвокс** (высота тона зависит от расстояния до руки над сонаром), **рисовалка** джойстиком и **музыкальная шкатулка** с эквалайзером. Рекорды сохраняются во флеш. |
| **Инструменты** | **Рулетка** на сонаре (три замера дают площадь и объём комнаты), **счётчик проходов** (сонар поперёк двери считает людей), настройка RGB-ленты, I2C-сканер (подсказывает, какой модуль сидит на найденном адресе), WiFi-сканер, секундомер с кругами, журнал событий, фонарик. |
| **WiFi** | Точка доступа и одновременное подключение к домашнему роутеру. Есть mDNS: `http://verygood.local`. |
| **Настройки** | Около 30 параметров, все сохраняются в NVS. |
| **Telegram-бот** | Сообщает о тревоге, постановке и снятии с охраны, жаре или холоде, по желанию о движении. Команды: `/status`, `/arm`, `/disarm`, `/relay_on`, `/relay_off`, `/beep`. |
| **RGB-лента WS2812** | Режимы: статус охраны, радуга, цвет по температуре, огонь, ночник по движению, индикатор расстояния, светомузыка. При тревоге мигает как полицейская мигалка, будильник включает «рассвет». |
| **Веб-панель** | Живые показания, графики, кнопки охраны и реле, виртуальный пульт (дублирует энкодер), настройки, журнал и **обновление прошивки по воздуху**. |
| **Заставка** | Через N минут бездействия включается заставка от выгорания OLED: плавающая температура на звёздном фоне. Экран просыпается от датчика движения. |
| **Консоль** | Команды через Serial (115200): `help`, `status`, `arm`, `disarm`, `relay on/off`, `sta <ssid> <пароль>`, `log`, `reboot`. |

Если какого-то модуля нет, прошивка это переживёт: датчики находятся автоматически, а неподключённые показываются как `--`. DS18B20 можно подключить на ходу. Джойстик определяется при старте, PIR и сонар не дают ложных срабатываний без датчика благодаря подтяжкам к земле.

## Подключение

Плата: **ESP32 DevKit V1, 30 пинов (ESP32-WROOM-32)**. Подойдёт и 38-пиновая: номера GPIO те же.

| Модуль | Вывод модуля | GPIO ESP32 | Примечание |
|---|---|---|---|
| OLED 0.96" SSD1306 (I2C) | SDA | **21** | питание 3.3 В |
| | SCL | **22** | |
| Энкодер KY-040 | CLK | **32** | |
| | DT | **33** | |
| | SW | **25** | |
| DHT11 | DATA | **4** | подтяжка 10 кОм (на модуле обычно есть) |
| DS18B20 | DQ | **5** | **резистор 4.7 кОм между DQ и 3.3 В обязателен**; можно повесить несколько датчиков на одну шину |
| HC-SR04 | TRIG | **26** | питание 5 В |
| | ECHO | **27** | ⚠️ сигнал 5 В, нужен **делитель 1 кОм / 2 кОм** |
| PIR HC-SR501 / AM312 | OUT | **14** | питание 5 В, выход 3.3 В |
| Джойстик KY-023 | VRx | **34** | питание **3.3 В** (не 5 В!) |
| | VRy | **35** | |
| | SW | **13** | |
| Пассивный бузер | + | **18** | через транзистор будет громче |
| Реле | IN | **19** | у модулей с активным LOW включите «Реле инверсия» |
| RGB-лента/кольцо WS2812B *(необязательно)* | DIN | **23** | питание 5 В; на 8–16 светодиодов хватит USB. Количество задаётся в «Инструменты → RGB-подсветка» |
| Аналоговый датчик | OUT | **36 (VP)** | фоторезистор, потенциометр, датчик почвы; включите в настройках |
| Светодиод | | **2** | встроенный |

Все пины собраны в [`src/config.h`](src/config.h), меняйте их под свою схему.

### Где что на 30-пиновой плате

Вид сверху, антенна вверху, USB внизу:

```
                    ┌──── антенна ────┐
                 EN ┤●               ●├ D23  RGB-лента WS2812 DIN
 Аналог. датчик  VP ┤●  (GPIO36)     ●├ D22  OLED SCL
       свободен  VN ┤●  (GPIO39)     ●├ TX0  (USB, не трогать)
    Джойстик VRx D34┤●               ●├ RX0  (USB, не трогать)
    Джойстик VRy D35┤●               ●├ D21  OLED SDA
     Энкодер CLK D32┤●               ●├ D19  Реле IN
      Энкодер DT D33┤●               ●├ D18  Бузер
      Энкодер SW D25┤●               ●├ D5   DS18B20 DQ (+4.7к к 3V3)
      Сонар TRIG D26┤●               ●├ TX2  свободен (GPIO17)
      Сонар ECHO D27┤● ← делитель!   ●├ RX2  свободен (GPIO16)
         PIR OUT D14┤●               ●├ D4   DHT11 DATA
     не занимать D12┤●               ●├ D2   встроенный светодиод
     Джойстик SW D13┤●               ●├ D15  свободен
                 GND┤●               ●├ GND
    5 В (от USB) VIN┤●               ●├ 3V3
                    └────── USB ──────┘
```

**Питание.** На 30-пиновой плате всего два GND, поэтому удобнее вывести питание на шины макетной платы:
- **VIN (5 В)**: сонар HC-SR04, датчик движения HC-SR501, модуль реле, RGB-лента;
- **3V3**: OLED, энкодер (`+`), DHT11, DS18B20, джойстик.

Энкодер питайте от 3.3 В: подтяжки на модуле KY-040 тогда не подадут 5 В на ESP32.

**Свободные пины для других модулей:** D15, TX2 (GPIO17), RX2 (GPIO16). VN (GPIO39) работает только как вход, подходит для аналогового датчика. D12 лучше не занимать: если при включении на нём высокий уровень, плата не загрузится.

## Сборка и прошивка

### PlatformIO (рекомендуется)

1. Установите [VS Code](https://code.visualstudio.com/) и расширение **PlatformIO IDE**.
2. Откройте папку проекта. Библиотеки скачаются сами.
3. Нажмите **Upload** (→) в нижней панели или выполните:

```bash
pio run -t upload        # собрать и прошить
pio device monitor       # открыть консоль
```

### Arduino IDE

1. Установите ядро **esp32 by Espressif** версии 2.0.x (в 3.x поменялся API LEDC).
2. Установите библиотеки: **U8g2**, **DHT sensor library** (Adafruit), **Adafruit Unified Sensor**, **OneWire**, **DallasTemperature**, **ArduinoJson** (v7), **Adafruit NeoPixel**.
3. Переименуйте папку `src` в `VeryGoodESP32`, а `main.cpp` в `VeryGoodESP32.ino`, затем откройте `.ino`.
4. Плата: *ESP32 Dev Module* (или *DOIT ESP32 DEVKIT V1*). Нажмите «Загрузить». Если загрузка не начинается, зажмите кнопку **BOOT** при появлении `Connecting...`.

### Готовая прошивка

Каждый push собирается в GitHub Actions. Файлы `firmware.bin`, `bootloader.bin` и `partitions.bin` лежат в артефактах сборки (вкладка **Actions**). Если на устройстве уже стоит эта прошивка, обновить её можно через веб-панель: раздел «Обновление прошивки».

Прошить готовые файлы без PlatformIO можно через [ESP Web Flasher](https://espressif.github.io/esptool-js/) прямо из Chrome или командой `esptool`:

| Файл | Адрес |
|---|---|
| `bootloader.bin` | `0x1000` |
| `partitions.bin` | `0x8000` |
| `boot_app0.bin` | `0xE000` |
| `firmware.bin` | `0x10000` |

```bash
esptool.py --chip esp32 --baud 921600 write_flash 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin
```

## Управление

| Действие | Энкодер | Джойстик |
|---|---|---|
| Листать / менять значение | крутить | вверх / вниз |
| Выбрать / OK | короткое нажатие | нажать на ручку |
| Назад | **долгое нажатие** (0.6 с) | влево или долгое нажатие |

В играх джойстик работает как геймпад, а энкодер поворачивает змейку и двигает платформу.

## Веб-панель

1. Подключитесь к WiFi **`VeryGood-ESP32`**, пароль **`esp32pass`**.
2. Откройте **http://192.168.4.1**.
3. Чтобы устройство было доступно в домашней сети, введите SSID и пароль роутера в блоке «WiFi-сеть». После этого оно откроется по адресу `http://verygood.local` или по IP, который покажет экран WiFi.

## Telegram-бот

1. Напишите в Telegram [@BotFather](https://t.me/BotFather) команду `/newbot` и получите токен.
2. Подключите устройство к домашнему роутеру: в веб-панели блок «WiFi-сеть», боту нужен интернет.
3. В блоке «Telegram-бот» вставьте токен и выберите «Включён: да».
4. Напишите своему боту любое сообщение. Устройство само привяжется к вашему чату, а сообщения из чужих чатов будет игнорировать.

HTTP API:

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/data` | все показания в JSON |
| GET | `/api/history?id=0..4` | история для графика |
| GET | `/api/log` | журнал событий |
| GET/POST | `/api/settings` | чтение и запись настроек |
| POST | `/api/cmd?c=arm\|disarm\|relay_on\|relay_off\|beep\|reboot` | команды |
| POST | `/api/cmd?c=ev&e=1..6` | виртуальная кнопка (1 вверх, 2 вниз, 3 влево, 4 вправо, 5 OK, 6 назад) |
| POST | `/api/time?t=<unix>` | задать время (веб-панель делает это сама) |
| POST | `/update` | загрузка новой прошивки (.bin) |

Это удобно для Home Assistant, Node-RED или своих скриптов.

## Структура кода

```
src/
  config.h         пины и константы
  main.cpp         setup/loop, загрузочный экран, Serial-консоль
  settings.*       настройки в NVS, рекорды игр
  input.*          энкодер (прерывания), кнопки, джойстик → единые события
  sensors.*        DHT11, DS18B20, HC-SR04 (на прерываниях), PIR, АЦП, история
  logic.*          охрана, реле/термостат, оповещения, светодиод, журнал
  sound.*          неблокирующие мелодии и эффекты на бузере
  melodies.*       мелодии для шкатулки и будильника
  clock.*          время (NTP, часовой пояс), будильник
  tg.*             Telegram-бот (в отдельной задаче FreeRTOS)
  leds.*           RGB-лента WS2812
  display.*        U8g2, шрифты с кириллицей, иконки, уведомления
  ui.*             стек экранов, заставка, списки с анимированным курсором
  scr_*.cpp        экраны: меню, датчики, охрана/реле, игры, инструменты, настройки
  net.* web_page.h WiFi, веб-сервер, REST API, OTA
```

### Как добавить свой модуль

1. Добавьте пин в `config.h`.
2. Опросите датчик в `sensors.cpp`, в `sensorsUpdate()`, и положите значение в `SensorData`.
3. Сделайте экран: класс-наследник `Screen` с методами `draw()` и `event()`, по образцу любого из `scr_*.cpp`.
4. Добавьте пункт в `MAIN_ITEMS` (`scr_menu.cpp`) или в меню «Инструменты».
5. Чтобы значение появилось в вебе, допишите его в `handleData()` в `net.cpp`.

Иконки рисуются прямо в коде как ASCII-арт (`#` — пиксель) в `display.cpp`, их легко поправить.

## Если что-то не работает

- **Экран пустой**: проверьте адрес (0x3C), SDA/SCL и питание. Если у вас дисплей 1.3" на SH1106, поменяйте класс дисплея в `display.cpp`.
- **Энкодер шагает через раз или по два**: поменяйте `ENC_STEPS_PER_DETENT` в `config.h` (2 или 4). Направление переключается в настройках.
- **DS18B20 показывает `--`**: почти всегда виноват отсутствующий резистор 4.7 кОм.
- **Сонар всё время «нет эха»**: проверьте делитель на ECHO и питание 5 В.
- **Джойстик «не обнаружен»**: он определяется при включении, поэтому подключайте его до подачи питания. Питайте его от 3.3 В.
- **Telegram пишет «нет интернета»**: бот работает только через роутер. В режиме точки доступа интернета у ESP32 нет.
- **Меню само листается**: шумит неподключённый джойстик. Отключите его в настройках.
